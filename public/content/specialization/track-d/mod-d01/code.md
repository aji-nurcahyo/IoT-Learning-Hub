# Implementasi Kode & Walkthrough: Modul D01

## 1. Arsitektur Modul Simulasi
Modul [hardware_roofline_model_sim.py](src/hardware_roofline_model_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Embedded AI Architecture, Hardware Accelerators & Neural Processing Units.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-d/mod-d01/src/hardware_roofline_model_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
