# Implementasi Kode & Walkthrough: Modul D03

## 1. Arsitektur Modul Simulasi
Modul [tinyml_qat_compression_sim.py](src/tinyml_qat_compression_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Deep TinyML: Quantization-Aware Training, Structured Pruning & Knowledge Distillation.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-d/mod-d03/src/tinyml_qat_compression_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
