# Implementasi Kode & Walkthrough: Modul A06

## 1. Arsitektur Modul Simulasi
Modul [building_capstone_controller_sim.py](src/building_capstone_controller_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Autonomous Micro-Climate & Demand-Response Building Controller (Capstone Project).

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-a/mod-a06/src/building_capstone_controller_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
