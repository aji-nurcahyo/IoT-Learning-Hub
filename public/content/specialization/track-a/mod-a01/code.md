# Implementasi Kode & Walkthrough: Modul A01

## 1. Arsitektur Modul Simulasi
Modul [building_coexistence_cir_sim.py](src/building_coexistence_cir_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Smart Building Architecture, Zoning & Multi-Protocol Coexistence.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-a/mod-a01/src/building_coexistence_cir_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
