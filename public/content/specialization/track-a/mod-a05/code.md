# Implementasi Kode & Walkthrough: Modul A05

## 1. Arsitektur Modul Simulasi
Modul [lifesafety_interlock_evacuation_sim.py](src/lifesafety_interlock_evacuation_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Life-Safety Integration, Fail-Safe Interlocks & Emergency Evacuation Routing.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-a/mod-a05/src/lifesafety_interlock_evacuation_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
