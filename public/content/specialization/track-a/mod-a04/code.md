# Implementasi Kode & Walkthrough: Modul A04

## 1. Arsitektur Modul Simulasi
Modul [building_energy_peakshaving_sim.py](src/building_energy_peakshaving_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Building Energy Optimization, Peak-Shaving & Sub-Metering.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-a/mod-a04/src/building_energy_peakshaving_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
