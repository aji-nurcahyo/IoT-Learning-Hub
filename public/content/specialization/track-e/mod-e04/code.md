# Implementasi Kode & Walkthrough: Modul E04

## 1. Arsitektur Modul Simulasi
Modul [municipal_contention_queue_sim.py](src/municipal_contention_queue_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Municipal Network Contention, Slotted ALOHA & Priority Queueing.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-e/mod-e04/src/municipal_contention_queue_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
