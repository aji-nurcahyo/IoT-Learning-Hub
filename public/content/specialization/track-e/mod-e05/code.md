# Implementasi Kode & Walkthrough: Modul E05

## 1. Arsitektur Modul Simulasi
Modul [geospatial_telemetry_h3_sim.py](src/geospatial_telemetry_h3_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Geospatial Telemetry, Geofencing & Spatial Aggregation (H3 / S2).

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-e/mod-e05/src/geospatial_telemetry_h3_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
