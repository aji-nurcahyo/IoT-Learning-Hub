# Implementasi Kode & Walkthrough: Modul E01

## 1. Arsitektur Modul Simulasi
Modul [smart_city_ngsild_multitenant_sim.py](src/smart_city_ngsild_multitenant_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Smart City IoT Systems Engineering, Urban Topologies & Municipal Architecture.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-e/mod-e01/src/smart_city_ngsild_multitenant_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
