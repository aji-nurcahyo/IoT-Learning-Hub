# Implementasi Kode & Walkthrough: Modul E06

## 1. Arsitektur Modul Simulasi
Modul [city_scale_capstone_platform.py](src/city_scale_capstone_platform.py) mengimplementasikan logika rekayasa dan model komputasi untuk City-Scale Multi-Tenant IoT Platform & Telecommunications Integration Capstone.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-e/mod-e06/src/city_scale_capstone_platform.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
