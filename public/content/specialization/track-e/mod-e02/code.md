# Implementasi Kode & Walkthrough: Modul E02

## 1. Arsitektur Modul Simulasi
Modul [urban_rf_propagation_sim.py](src/urban_rf_propagation_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Urban RF Propagation, Empirical Path Loss Models & Multipath Fading Analysis.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-e/mod-e02/src/urban_rf_propagation_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
