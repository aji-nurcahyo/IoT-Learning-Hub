# Implementasi Kode & Walkthrough: Modul C06

## 1. Arsitektur Modul Simulasi
Modul [agricultural_capstone_network_sim.py](src/agricultural_capstone_network_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Autonomous LoRaWAN Agricultural Microclimate Network (Capstone Project).

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-c/mod-c06/src/agricultural_capstone_network_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
