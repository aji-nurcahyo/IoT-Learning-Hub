# Implementasi Kode & Walkthrough: Modul C02

## 1. Arsitektur Modul Simulasi
Modul [sensor_calibration_drift_sim.py](src/sensor_calibration_drift_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Precision In-Situ Calibration, Temperature Drift & Sensor Aging Physics.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-c/mod-c02/src/sensor_calibration_drift_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
