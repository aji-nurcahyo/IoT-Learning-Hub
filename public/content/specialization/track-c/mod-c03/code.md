# Implementasi Kode & Walkthrough: Modul C03

## 1. Arsitektur Modul Simulasi
Modul [lorawan_canopy_propagation_sim.py](src/lorawan_canopy_propagation_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk LoRaWAN Topography Planning, Fresnel Zone & Canopy Path Loss Modeling.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-c/mod-c03/src/lorawan_canopy_propagation_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
