# Implementasi Kode & Walkthrough: Modul C04

## 1. Arsitektur Modul Simulasi
Modul [solar_energy_harvesting_sim.py](src/solar_energy_harvesting_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Energy Harvesting, Solar Irradiance Profiling & Supercapacitor Dimensioning.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-c/mod-c04/src/solar_energy_harvesting_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
