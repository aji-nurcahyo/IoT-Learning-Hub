# Implementasi Kode & Walkthrough: Modul C05

## 1. Arsitektur Modul Simulasi
Modul [fao56_evapotranspiration_sim.py](src/fao56_evapotranspiration_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Evapotranspiration Analytics, FAO-56 Penman-Monteith & Precision Irrigation.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-c/mod-c05/src/fao56_evapotranspiration_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
