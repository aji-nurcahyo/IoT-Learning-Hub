# Implementasi Kode & Walkthrough: Modul B06

## 1. Arsitektur Modul Simulasi
Modul [industrial_pdm_capstone_platform.py](src/industrial_pdm_capstone_platform.py) mengimplementasikan logika rekayasa dan model komputasi untuk Capstone: Edge Predictive Maintenance System with High-Speed Sampling.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-b/mod-b06/src/industrial_pdm_capstone_platform.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
