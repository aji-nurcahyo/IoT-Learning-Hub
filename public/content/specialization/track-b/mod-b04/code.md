# Implementasi Kode & Walkthrough: Modul B04

## 1. Arsitektur Modul Simulasi
Modul [vibration_feature_envelope_sim.py](src/vibration_feature_envelope_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Time & Frequency Domain Feature Engineering for Rotating Machinery.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-b/mod-b04/src/vibration_feature_envelope_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
