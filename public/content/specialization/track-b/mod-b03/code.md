# Implementasi Kode & Walkthrough: Modul B03

## 1. Arsitektur Modul Simulasi
Modul [modbus_polling_cycle_sim.py](src/modbus_polling_cycle_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Industrial Fieldbus Engineering: Modbus RTU/TCP, OPC UA Information Models & TSN.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-b/mod-b03/src/modbus_polling_cycle_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
