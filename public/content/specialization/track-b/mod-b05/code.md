# Implementasi Kode & Walkthrough: Modul B05

## 1. Arsitektur Modul Simulasi
Modul [sil_voting_reliability_sim.py](src/sil_voting_reliability_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk Industrial Reliability, Functional Safety & Safe State Control.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-b/mod-b05/src/sil_voting_reliability_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
