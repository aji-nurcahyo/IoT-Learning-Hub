# Implementasi Kode & Walkthrough: Modul B02

## 1. Arsitektur Modul Simulasi
Modul [vibration_mounting_sim.py](src/vibration_mounting_sim.py) mengimplementasikan logika rekayasa dan model komputasi untuk High-Frequency Vibration, Acoustic Emission & Sensor Installation Physics.

Kode diorganisasikan secara modular, deterministik, dan dapat dieksekusi secara mandiri pada lingkungan Python standar tanpa dependensi cloud berbayar.

---

## 2. Cara Menjalankan Simulasi
Eksekusi langsung dari terminal project root:

```bash
python public/content/specialization/track-b/mod-b02/src/vibration_mounting_sim.py
```

Hasil eksekusi terekam lengkap pada berkas bukti [outputs.md](outputs.md).
