# Catatan bukti pengujian — template

Status: Belum diuji. Formulir kosong bukan bukti verifikasi.

- Chapter dan commit source:
- Tanggal, penulis, reviewer:
- Jenis: compile / software / simulator / hardware
- OS dan versi toolchain/library:
- Simulator dan versinya jika relevan:
- Board, model, revisi, serta identitas komponen jika relevan:
- Datasheet dan electrical limits:
- Wiring, pin mapping, driver/protection:
- Command build, flash, dan run:
- Kondisi pengujian dan instrumen:
- Output asli / path log:
- SHA-256 file bukti:
- Kriteria penerimaan dan hasil aktual:
- Kegagalan, batasan, dan yang belum diuji:

Jangan mengisi latency, packet loss, konsumsi daya, atau akurasi Sensor tanpa menjalankan pengukuran yang sesuai. Redaksi secret sebelum menyimpan log; hitung hash setelah redaksi dan dokumentasikan redaksi.
