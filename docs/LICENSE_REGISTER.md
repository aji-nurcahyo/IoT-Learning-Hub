# Register lisensi dan atribusi

Kode fondasi IoT ditulis baru untuk proyek ini. Identitas pembuat: Aji Pamungkas Tri Nurcahyo, Institut Teknologi Sumatera. Hak cipta konten baru tetap pada pemegang hak; keputusan pemberian lisensi distribusi publik belum ditetapkan oleh pemilik. Istilah perpustakaan terbuka menjelaskan akses/tujuan platform, bukan otomatis memberikan lisensi terhadap setiap materi.

Tidak mereproduksi materi kursus Python/AI, teks standar, datasheet, atau gambar lembaga. Referensi ditautkan; tidak ada klaim sertifikasi/endorsement. Kedua proyek lokal menjadi referensi desain dan arsitektur. Notice Reveal.js dari referensi dipertahankan byte-for-byte pada LICENSE.upstream.

| Komponen | Lisensi utama | Penggunaan |
| --- | --- | --- |
| React, React DOM | MIT | Antarmuka |
| Vite, TypeScript | MIT / Apache-2.0 | Build dan typing |
| Reveal.js | MIT | Presentasi |
| KaTeX | MIT | Math |
| unified, react-markdown, remark, rehype | MIT | Renderer Markdown |
| highlight.js | BSD-3-Clause | Syntax highlighting |
| Lucide | ISC | Icon UI |
| Zod | MIT | Schema |
| Manrope, DM Sans | OFL-1.1 | Font lokal via Fontsource |
| Playwright | Apache-2.0 | Browser QA |

Versi dan deklarasi lisensi package terpasang dicatat di DEPENDENCY_LICENSES.json. Notice asli tetap berada pada package terpasang; bundler mempertahankan legal comments yang tersedia. Sebelum mendistribusikan ulang dependency/asset secara terpisah, sertakan license file terkait. Materi pihak ketiga baru harus dicatat dengan sumber, pemegang hak, lisensi, modifikasi, dan lokasi file.
