# Roadmap

## Tahap fondasi

Katalog 40 chapter dan lima track, Getting Started terpisah, renderer/presentasi, schema resource, publication guard, dokumentasi, static routing dan QA. Semua chapter tetap Coming Soon.

## Tahap berikutnya

1. Tulis chapter 01–03 terlebih dahulu: tujuan, konsep, sumber primer spesifik, latihan, tugas, dan rubrik. Review kualitas sebelum publikasi; gunakan jumlah slide sesuai lingkup.
2. Pilih satu model/revisi board untuk praktik 04–09. Periksa schematic/datasheet, tentukan BOM, pin mapping, supply, driver/protection, dan versi toolchain. Siapkan jalur simulator atau software yang sesuai.
3. Bangun contoh runnable dan fixture telemetry sintetis berlabel jelas. Simpan bukti compile/software/simulator, lalu uji hardware bila tersedia. Jangan mengisi pengukuran sebelum eksperimen.
4. Lengkapi capstone level 1. Uji konsistensi rubric metadata, tugas, dan kriteria penerimaan melalui review pedagogis.
5. Lanjutkan konektivitas lokal, MQTT, offline buffering, kemudian Gateway, storage, keamanan, dan lifecycle. Tambahkan regression tests sesuai praktik nyata.
6. Kembangkan level 4 dan track setelah fondasi terkait tersedia. Telaah spesifikasi terbaru dan lisensi data/model sebelum distribusi.
7. Setelah persetujuan pemilik: buat/pilih repository, review lisensi distribusi, push, dan jalankan workflow Pages manual. Uji ulang URL hosted; local HTTP QA bukan bukti deployment.

## Peningkatan yang dapat menyusul

Pemecahan bundle renderer, pemeriksaan aksesibilitas lintas browser, export PDF/PPTX hanya bila file nyata dibuat, pengujian broker/network otomatis, dan validasi kesesuaian rubric di artefak tugas. Tidak menambah fitur LMS.
