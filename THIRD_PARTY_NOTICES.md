# Atribusi pihak ketiga

Internet of Things Learning Hub dibuat untuk Aji Pamungkas Tri Nurcahyo, Institut Teknologi Sumatera.

Pola katalog, theme, navigasi, renderer chapter, presentasi, resource management, dan GitHub Pages dipelajari dari proyek lokal Alpro-python dan Kecerdasan Buatan atas instruksi pemilik. Kedua proyek tetap read-only. Implementasi UI/schema/renderer IoT ditulis baru; materi Python/AI dan komponen source mereka tidak disalin.

Referensi lokal mencatat asal beberapa komponen dari Pengkom Informatika ITERA (https://github.com/informatika-itera/pengkom). Karena komponen tersebut tidak disalin, atribusi ini menjelaskan rantai referensi, bukan klaim lisensi atas materi asal. Pemberitahuan MIT Reveal.js dari LICENSE.upstream dipertahankan tanpa perubahan.

Dependency yang digunakan mencakup React, React DOM, Vite, TypeScript, Reveal.js, KaTeX, unified/react-markdown/remark/rehype, highlight.js, Zod, Lucide, Fontsource (Manrope dan DM Sans), ESLint, dan Playwright. Hak cipta tetap pada pemegang hak masing-masing. Lihat docs/LICENSE_REGISTER.md dan docs/DEPENDENCY_LICENSES.json.
